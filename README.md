# Doomsday Guide

Static HTML site for GitHub Pages.

Everything (HTML, CSS, JS, data) lives in the single `index.html`. There is no build step, backend or framework. Progress and settings are stored in the visitor's browser (`localStorage`) and can be exported or imported as JSON.

Runtimes and Marvel links are curated by hand (series runtimes are estimates), and the News tab is static: update its dated entries and "last verified" date in `index.html` when you edit.

Open `index.html` locally, or enable GitHub Pages from the repository's `main` branch and root folder.
